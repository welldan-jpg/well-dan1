📚 教師業務判定アプリ

文部科学省の業務分類に基づいて、教師の業務の要否を判定するモバイルアプリケーション

React Native Expo TypeScript 教育DX

プロジェクト概要

このアプリケーションは、教師が日々の業務を入力することで、文部科学省が示す「学校と教師の業務の3分類」に基づいて、その業務が教師が担うべきものか、検討の余地があるか、または委譲可能かを判定します。

判定結果には詳細な理由とアドバイスが表示され、教師のウェルビーイング向上と業務最適化を支援します。

✨ 実装内容

🎯 業務判定機能

ホーム画面で業務名を入力すると、文科省の「学校と教師の業務の3分類」に基づいて判定を行います。

📊 判定結果表示

判定結果画面で詳細な理由とアドバイスを表示。ステータスに応じた色分け表示で直感的に理解できます。

📝 履歴管理

判定履歴はローカルストレージに自動保存。過去の判定結果を確認・削除できます。

🔗 研修案内

判定結果からWellDAN研修プログラムへの導線を提供。研修との連携で行動変容を促進します。

📧 メール送信

判定レポートをメール形式で生成・送信。個人情報の取り扱いについての詳細な但し書きを表示。

✅ テスト完備

業務判定ロジックのユニットテスト17件が全てパス。各画面のナビゲーションも正常に機能。

🚀 次のステップ

アプリケーションの機能をさらに拡張するための提案です。

1

AI連携による判定精度向上

現在のキーワードマッチングをサーバー側のLLM（大規模言語モデル）に置き換えることで、より自然な業務名の入力に対応し、判定精度を大幅に向上させることができます。

2

業務削減プランの自動生成

判定結果に基づいて、教師個人の業務削減プランを自動生成し、具体的なアクションアイテムと期限を提示する機能を追加することで、研修後の行動変容を促進できます。

3

学校全体の業務分析ダッシュボード

複数の教師の判定結果を集約し、学校全体の業務分布を可視化するダッシュボード機能を実装することで、管理職の業務改善計画立案をサポートできます。

⚠️ 重要な注記：

このアプリケーションは参考情報です。学校の実情に応じて、最終的な判断は学校管理職と相談の上で行ってください。判定結果は文部科学省の指針に基づいていますが、個別の状況によって判断が異なる場合があります。
